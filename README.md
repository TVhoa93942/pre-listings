# pre-listings — Phillips Real Estate property websites

One folder per property, served by GitHub Pages at `https://homes.billandred.com/<slug>/`
(and `https://tvhoa93942.github.io/pre-listings/<slug>/` until the custom domain is connected).

Built by the `pre-listing-engine` skill in the "PRE Sales & CMAs" Claude project. Each folder holds
`index.html`, `img/`, `qr.png`, `qr.svg` and the `site.json` it was built from. `index.html` at the
root is the listings directory. Do not hand-edit a property page: change its `site.json`, rebuild, commit.
